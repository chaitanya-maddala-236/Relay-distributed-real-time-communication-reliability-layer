Reliability controls

Pause consumption stops acknowledging. The server's in-flight window fills, delivery to this client stops, and if the burst continues the server disconnects it with SLOW_CONSUMER — while other clients are unaffected.

Drop connection kills the socket without closing the session, so reconnecting replays what was missed via RESUME.

Messages

Messages are published through POST /v1/publish, which assigns the sequence number server-side, so ordering holds no matter which node or publisher a message came from.
